# 算力行业咨询

> 算力行业动态跟踪与情报归档仓库
> 维护：中国电信金华分公司 · 算力生态事业部
> 自动化：每周一 09:00 更新一期

---

## 简介

本仓库用于持续跟踪 **AI 算力行业**的公开动态与情报，覆盖智算中心建设、算力网络、国产芯片、算力租赁/Token 服务、政策法规等方向，按周归档。

## 目录结构

```
算力行业咨询/
├── README.md          # 本文件
├── 行业动态/          # 按周归档的行业动态（YYYY-MM-DD.md）
├── 政策法规/          # 国家/部委/地方政策原文与要点
├── 研究报告/          # 券商研报、白皮书要点摘编
└── 专题/              # 专题跟踪（如国产芯片、算电协同）
```

## 更新机制

| 项目 | 说明 |
|---|---|
| 频率 | 每周一 09:00 自动更新 |
| 归档 | `行业动态/YYYY-MM-DD.md` |
| 维度 | 政策法规 / 产业市场 / 技术产品 / 企业资本 / 海外动态 |
| 来源 | 公开网络检索，**逐条标注来源链接** |
| 纪律 | 只收录可溯源信息；不确定的数据标注「待核实」 |
